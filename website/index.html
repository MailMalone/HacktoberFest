PR Triage
Local · Read-only · Evidence first
A calmer Hacktoberfest inbox

First pass, with receipts.

PR Triage helps maintainers sort genuine contributions from small fixes, uncertain cases, and suspicious patterns. Every recommendation points back to concrete signals.

Maintainer asks

“Is this a real contribution, and what should I check next?”

PR Triage answers locally with diff, tests, contributor history, linked issues, and a clear confidence score.

01 / FETCH

Read the PR

Pull public metadata and changed-file patches through GitHub’s read-only API.

02 / MEASURE

Extract signals

Count changes, detect tests and CI edits, check contributor history, and validate issue links.

03 / EXPLAIN

Show the call

Gemini returns a structured verdict. Hard policy checks keep uncertain cases in maintainer review.

One output · four outcomes

VerdictWhat it meansWhat the maintainer sees
substantiveMeaningful code or test workEvidence summary and a specific, respectful public comment draft
minorSmall but legitimate improvementEvidence summary and a kind comment draft with a useful next step
suspected-spamMultiple independent strong indicatorsPrivate maintainer note; no public comment draft
needs-reviewMissing, conflicting, or low-confidence evidencePrivate uncertainty note; no public comment draft

Data boundary

Nothing gets posted.

The CLI sends GitHub GET requests only. Comment drafts stay in the terminal. Gemini receives a minimal evidence packet only after a one-time notice and acknowledgment.
