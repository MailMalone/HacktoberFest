Inactive claim monitor

Find assigned issues with no recent visible GitHub activity. Includes assignee replies and linked PR progress. This scan never sends messages, closes PRs, or removes assignments. People may still be working offline.

Uses explicit issue assignments. Free-text claims alone are not counted. Results are evidence for a maintainer to review.
